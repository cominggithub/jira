🛠️ Available Tools

list_switches

Purpose: Display all configured SONiC switches

Parameters: None

Returns: Table format list of switches with connection details

add_switch

Purpose: Add new SONiC switch to configuration

Parameters: name, ip, username (optional), password (optional), port (optional), timeout (optional)

Returns: Success confirmation or validation error

probe_switch

Purpose: Test SSH connectivity to a switch

Parameters: identifier (name or IP)

Returns: Connection status, timing, and SONiC detection results

show_version

Purpose: Get SONiC version and platform information

Parameters: identifier (name or IP)

Returns: Parsed version info including SONiC version, platform, ASIC, build date

show_err

Purpose: Extract and analyze system error logs

Parameters: identifier, lines (default: 100), severity_filter (all/critical/error/warning)

Returns: Classified error logs with severity analysis and recommendations

show_config

Purpose: Retrieve switch configuration data

Parameters: identifier, config_type (all/config_db/frr)

Returns: JSON-formatted configuration data (config_db.json, FRR config)

show_status

Purpose: Comprehensive system health monitoring

Parameters: identifier

Returns: JSON status including CPU/memory/disk usage, hardware status, health analysis

get_sai_record

Purpose: Get SAI (Switch Abstraction Interface) records and logs

Parameters: identifier, component (all/sai_logs/orchagent_logs/syncd_logs/sai_dump), lines (default: 100)

Returns: SAI logs analysis with JIRA query suggestions, component breakdown, and recommendations
